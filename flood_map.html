Lymis Methodology

Lymis (Localized Yield Monitoring & Flood Impact System) is a dedicated flood forecasting tool of the World Disaster Center. It provides accurate, near-real-time flood intelligence to enable governments, humanitarian organizations, and communities to prepare, respond, and mitigate flood disasters.

1. Data Acquisition

Lymis ingests data from the Google Flood Forecasting API as its primary source. The backend Python script automates this process:

  • fetch_gauges(): Retrieves metadata for thousands of river gauges across 80+ countries. It filters for quality-verified gauges with valid coordinates.
  • fetch_forecasts(): Queries the last 30 days of forecast data for all collected gauges, using efficient batching to handle large volumes of requests.

2. AI-Powered Prediction

To provide forward-looking intelligence, Lymis uses Meta's Prophet time-series forecasting model. It decomposes a time series into several components:

  • prophet_forecast(): For each gauge, the historical data is fed into a Prophet model. The model learns daily seasonalities and trends from the data.
  • It then generates a 7-day forward prediction, estimating the likely water levels. This predictive layer is crucial for early warning systems.
$$ y(t) = g(t) + s(t) + h(t) + \epsilon_t $$
Where:
  • $g(t)$: The trend function, modeling non-periodic changes.
  • $s(t)$: The seasonality function, representing periodic changes (e.g., daily, weekly).
  • $h(t)$: The holidays component, modeling the effects of irregular events.
  • $\epsilon_t$: The error term, representing any idiosyncratic changes.

3. Data Integration & Output

The final step combines all data streams into a single, actionable format.

  • merge_and_save(): This function merges the gauge metadata (location, name), historical API forecasts, and the 7-day Prophet predictions into a single JSON object for each gauge.
  • The resulting flood_full_data.json file powers this entire web application, ensuring all data is comprehensive and ready for visualization. The entire process is scheduled to run automatically every 24 hours.
